Thermodynamics, open source

A thermodynamics textbook written in LaTeX that anyone can read, print or adapt. It covers classical and statistical thermodynamics, from basic concepts to partition functions.

View on GitHub Report an issue Fork the project

What's in it

Explanations and derivations written out in full, worked examples and problems, and figures. The LaTeX source is part of the repository, so instructors can change chapters to suit their course and students can rebuild the PDF themselves.

Topics

  • Basic concepts
  • First law
  • Second law
  • Entropy
  • Free energy
  • Chemical potential
  • Phase equilibria
  • Mixtures
  • Statistical mechanics
  • Ensembles
  • Partition functions
  • Applications

How to use it

  1. Open the GitHub repository to see the full source.
  2. Download the PDF to read or print.
  3. Clone the repository to compile it from the LaTeX source.
  4. Open an issue for errors or suggestions.
  5. Send improvements as pull requests.
