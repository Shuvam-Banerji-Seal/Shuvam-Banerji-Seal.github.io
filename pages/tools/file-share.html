Beam Serverless file sharing

Files travel directly device-to-device through an encrypted WebRTC channel. Nothing is uploaded anywhere. This page only helps the two devices find each other by trading a short code. Both devices must have this page open at the same time.

disconnected

Step 1: your code

Step 2: their reply code

Drop files here or click to choose. They are sent instantly.

How it connects: both devices exchange handshake codes manually (chat, email, anything else), then negotiate a direct path using public STUN servers. Traffic is DTLS-encrypted end to end and never touches any server. Devices behind very restrictive corporate NATs may fail to connect. Try a home or mobile network.
