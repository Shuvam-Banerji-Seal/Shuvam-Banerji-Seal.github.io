How it connects: both devices exchange handshake codes manually (chat, email — anything), then negotiate a direct path using public STUN servers. Traffic is DTLS-encrypted end to end and never touches any server. Devices behind very restrictive corporate NATs may fail to connect — try a home or mobile network.
